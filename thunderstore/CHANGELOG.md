# Changelog

## 1.1.0
- New custom 3D model and textures for the Bronze Battleaxe, replacing the recoloured iron Battleaxe model.
  The inventory icon is now rendered from the new model, and the swing trail follows the new blade.
- If the model can't be loaded, the item falls back to the previous recoloured iron model.
- Model based on "Glass Battleaxe, 1958 Tris, Low Poly" by leonsavelind, CC BY 4.0 (see README for credits).

## 1.0.0
- Initial release: Bronze Battleaxe (Forge level 2, bronze-tier stats) using the iron Battleaxe's model recoloured bronze.
- Swing speed increases with Axes skill (configurable, up to +25% at skill 100).
